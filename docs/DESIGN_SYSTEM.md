# デザインシステム v0.4

## 目的

日本語読解に不安がある学習者が、休憩時間に片手で操作し、母語補助から日本語のみへ移行できる画面を作る。

## 視覚方針

- 背景：ほぼ白に近い淡い青緑
- 主色：濃い青緑。学習開始、進捗、選択状態
- 副色：オレンジ。2号マーク、分野タグ、注意の識別
- 警告：淡い黄。内部レビュー状態を常時明示
- 角丸：問題カードと主要パネルは大きめ、表や小部品は控えめ
- 影：最小限。境界線と余白で階層を作る

## タイポグラフィ

- 日本語可読性を優先したシステムサンセリフ
- 問題文は本文より明確に大きくする
- 支援文は色と背景を変え、本文と混同しない
- `ruby` と `rt` により専門語だけへふりがなを付ける

## 画面構造

```text
ブランド＋通信状態
内部レビュー警告
主ナビゲーション
画面本文
```

スマホでは主ナビゲーションを横スクロール可能とし、主要機能を隠さない。

## コンポーネント

- Primary button：青緑、主要な一手
- Secondary button：淡い青緑、補助的な開始
- Dark button：模試など明確に別モード
- Ghost button：分析、書き出し、戻る
- Choice button：4択。選択、正解、不正解を状態表示
- Support toggle：ふりがな、やさしい日本語、Bahasa
- Pill：分野、トピック、学習／模試状態
- Metric card：正答率、解答数、復習数
- Review card：根拠と承認候補を確認

## アクセシビリティ

- 主要操作は概ね44px以上を目標
- 選択状態を色だけでなく枠・文字でも示す
- `aria-live` で正誤を通知
- 模試タイマーは文字で表示
- 横方向のオーバーフローを発生させない
- `prefers-reduced-motion` を尊重

## 既存プロトタイプからの継承

- 2号のオレンジ角丸マーク
- 青緑とオレンジの配色
- 大きい日本語問題文
- 余白のある単一列スマホ画面
- 管理画面の4指標と14日活動量
- レビュー状態の常時警告
