# 学習支援レベル仕様

## 1. 目的と適用範囲

この仕様は、インドネシア人学習者が日本語の畜産農業問題を理解し、補助を段階的に減らして最終的に日本語だけで解けるようにするための表示・保存・評価ルールを定める。

- 日本語の問題文と選択肢を主教材とし、インドネシア語へ置き換えない。
- やさしい日本語、ふりがな、重要語、設問意図、インドネシア語は日本語理解の補助として扱う。
- 模擬試験は設定や習熟度にかかわらず日本語のみとし、回答中に学習補助や途中解説を表示しない。
- このfeature branchのコンテンツ編集は「代表16問パイロット」だけを対象とする。残り64問を新形式へ一括変換・承認するPhase 6は対象外である。

関連規範は [教材設計概要](PEDAGOGY_SPEC.md)、[ふりがな方針](FURIGANA_POLICY.md)、[インドネシア語翻訳ガイド](INDONESIAN_TRANSLATION_GUIDE.md)、[問題解説方針](QUESTION_EXPLANATION_POLICY.md)、[コンテンツレビュー・チェックリスト](CONTENT_REVIEW_CHECKLIST.md) を参照する。リポジトリ全体の入口は [README](../README.md) とする。

## 2. 既存モデルを正本とする

実フィールド名は `src/types.ts` と `public/question.schema.json` を正本とし、同じ意味のデータを重複して持たない。

| 要求概念 | 使用する既存フィールド |
|---|---|
| 日本語・やさしい日本語・インドネシア語・ruby | `LocalizedText.ja` / `easyJa` / `id` / `rubyJa` |
| 問題文 | `question` |
| 選択肢 | `choices[].text` |
| 正答を含む全選択肢の理由 | `choiceRationales[choiceId]` |
| 解説・正答理由の要約 | `explanation` |
| 重要語 | `learningSupport.keyTermIds` と `public/glossary-ja-id.json` |
| 設問意図・問題文型 | `learningSupport.questionPattern` と `lessonObjective` |
| 覚えるポイント | `learningSupport.memoryPoint` |
| 教材名・版・ページ・章 | `source.documentTitle` / `edition` / `pdfPage` / `section` |
| 出典確認 | `status` と `review.content` |
| インドネシア語確認 | `review.languageId` |
| 表示レベル | `settings.preferredSupportLevel` |
| 自動支援 | `settings.automaticSupport` と `studySupportMode` |
| 既存利用履歴 | `usedFurigana` / `usedEasyJapanese` / `usedIndonesian` / `elapsedMs` / `reason` |

新設が必要な場合も既存構造へ最小限追加する。パイロット問題のreviewでは `review.furigana`、`review.japaneseLearning`、`review.answerLeak`、日本語ポイントでは `learningSupport.languagePointKeys` を用いる。履歴では `openedKeywords`、`openedQuestionTranslation`、`openedChoiceTranslations`、`openedAnswerIndonesian` を用い、既存履歴の読み込み時は未定義を `false` とみなす。

## 3. 支援レベル0〜3

| レベル | 回答前に表示するもの | 回答前に隠すもの | 回答後 |
|---|---|---|---|
| Level 3 | 全ふりがな、やさしい日本語、全文訳、選択肢訳、読み・やさしい日本語・インドネシア語を含む重要語、インドネシア語の設問意図 | なし | 正解、正答理由、全選択肢理由、重要語、日本語ポイント、出典を表示する |
| Level 2 | ふりがな、読み・インドネシア語を含む重要語、インドネシア語の設問意図、全文訳を開くボタン | 全文訳の初期表示、選択肢訳の初期表示、やさしい日本語 | 正解、正答理由、全選択肢理由、重要語、日本語ポイント、出典を表示し、必要な翻訳を開ける |
| Level 1 | ふりがな、やさしい日本語による短い用語ヒント | 全文訳、選択肢訳、詳細な設問意図、回答前のインドネシア語 | 正解、正答理由、全選択肢理由、重要語、日本語ポイント、出典を表示し、インドネシア語を初めて開ける |
| Level 0 | 日本語問題・日本語選択肢のみ | ふりがな、やさしい日本語、重要語、設問意図、全翻訳、途中解説 | 正解、正答理由、全選択肢理由、重要語、日本語ポイント、出典を日本語だけで表示する。重要語にもふりがな・やさしい日本語・翻訳は付けない |

Level 0は学習セッション用の「補助なし挑戦」であり、模擬試験とは異なる。模擬試験では回答中の補助開閉、正誤、解説をすべて禁止する。

設問意図と重要語のインドネシア語表示は、問題全文訳・選択肢訳の開閉から独立させる。Level 2では全文訳を閉じたままでも、設問意図と重要語のインドネシア語を表示する。支援内容とは別に、操作ボタンや開閉ラベルは保存済みの表示言語に従う。

## 4. 既存設定との対応

- `guided`: 初期値はLevel 3。利用者が明示変更したレベルを尊重する。
- `adaptive`: `automaticSupport=true` とし、習熟度・過去の誤答原因・補助利用に基づきLevel 0〜3を決める。
- `japanese_only`: Level 0相当。ただし学習セッションなので採点後の解説は利用できる。
- `mock`: 強制的に日本語のみ。保存済み設定、UI言語、現在レベルを参照して補助を復活させてはならない。

自動支援は、補助を使った正解を「補助なしの正解」と同じ習得として扱わない。日本語不足で誤答した場合は知識不足と区別し、次回支援を強める判断材料にする。
補助を使った正解では、同じ支援レベルで2回続けて正解したときだけ次のレベルへ進める。Level 3だけでLevel 1相当以上、Level 2だけでLevel 0相当まで習得したとは判定しない。

## 5. 表示コンポーネントの責務

再利用可能な表示境界は次の責務で分離する。

- `renderRubyText`: 構造化された日本語とrubyを安全に表示する。
- `renderKeywordGlossary`: 重要語1〜5語を表示し、開いた履歴を記録する。
- `renderIndonesianTranslation`: 問題全文訳を開閉し、回答前後を区別する。
- `renderQuestionIntent`: 「何を選ぶか」を短く示す。正答情報は受け取らない。
- `renderChoiceTranslation`: 選択肢訳をレベルと回答前後に従って表示する。
- `renderAnswerExplanation`: 正解、正答理由、覚えるポイント、出典をまとめる。
- `renderWrongChoiceExplanation`: 各不正解の理由を選択肢ごとに表示する。
- `renderJapaneseLanguagePoint`: 否定・例外・選択指示などの日本語文型を説明する。
- `renderRetryWithoutSupport`: 回答後に同じ問題をLevel 0で再挑戦する。

## 6. 「日本語だけでもう一度解く」

- 回答と解説の表示後にのみ提示する。
- 同じ問題をLevel 0で開始し、選択肢順と正答は画面上で示さない。
- 元の履歴を上書きせず、新しい回答履歴を作る。
- 新履歴は `retryOfHistoryId` 等で元回答と関連付ける。
- 模擬試験中には表示しない。

## 7. 利用履歴とプライバシー

問題ごと・回答試行ごとに次を保存する。

- ふりがなを実際に表示したか
- やさしい日本語を実際に表示したか
- 重要語を開いたか
- 問題全文訳を開いたか
- 選択肢訳を開いたか
- 回答時の支援レベル
- 解答時間
- 誤答理由（`knowledge`、`japanese` 等）
- 補助なし再挑戦との関連

個人名、在留資格番号、住所、メール等は保存しない。開閉イベントを保存する場合は、ページを表示しただけで「使用」とせず、実際に可視になった時点を使用として記録する。

## 8. 代表16問パイロット

このbranchで新スキーマ・教材品質のレビュー対象にする問題IDは次の16問に固定する。

`q001`, `q004`, `q008`, `q013`, `q016`, `q029`, `q033`, `q035`, `q044`, `q045`, `q049`, `q055`, `q057`, `q078`, `q079`, `q080`

分類は単純知識、数値・単位、否定、手順、安全衛生、画像判断、長文を横断する。パイロットは `schemaVersion: "0.4.0"` で識別し、重複する `pilotOnly` フラグは追加しない。残り64問は従来の `0.3.0` のまま保持し、新形式へ変換した、レビュー済み、完成した、とは扱わない。

## 9. 受入条件

- Level 0〜3の表示差が単体テストとE2Eで確認できる。
- 言語と支援レベルが再起動後も維持される。
- 360px幅でLevel 3と回答後解説を開いても横スクロールが発生しない。
- 模擬試験DOMにインドネシア語、ruby、重要語、設問意図、翻訳ボタン、途中解説が存在しない。
- 既存の学習履歴、復習予定、模試中断データをmigration後も読み込める。
- パイロット16問以外をPhase 6相当として変更・承認しない。
