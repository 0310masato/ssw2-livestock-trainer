# UI忠実度確認台帳

比較対象：Phase 1プロトタイプのホーム、学習、管理画面 390×844
実装確認：Alpha v0.4、Playwright Chromium 390×844／1280×900

| 比較点 | 参照仕様 | Alpha v0.4 | 判断 |
|---|---|---|---|
| ブランド | オレンジの「2」＋濃青緑の名称 | 同じ構造、配色、比率 | 一致 |
| 警告帯 | 淡黄色に内部レビュー状態 | 版番号、source_checked、approved 0を常時表示 | 一致・情報更新 |
| ナビ | 青緑の文字、選択下線 | 同じ配置と選択下線 | 一致 |
| ホーム主役 | 大きい見出し、青緑CTA、淡い背景 | 同じ階層と余白 | 一致 |
| 学習画面 | 単一問題カード、4択、大きい操作 | 支援切替、自信、図を追加しつつ同じ骨格 | 機能拡張 |
| 管理画面 | 4指標、14日活動量、支援判断 | 同じ構造、分野表と出力を追加 | 機能拡張 |
| 配色 | 青緑＋オレンジ＋淡黄 | 色温度と意味を維持 | 一致 |
| モバイル | 390pxで単一列 | 横はみ出しなし、主要操作40px以上 | 合格 |
| デスクトップ | 中央コンテナ、広い余白 | 1280pxで再配置、9分野を3列 | 合格 |
| コピー | 毎日10問、母語から日本語へ | 主見出しを維持 | 一致 |

## 意図的な差分

1. ホームの主パネル内に「今日の進捗」を追加した。毎日10問の達成状況を最初の画面で確認するための機能上の追加。
2. 学習画面の初期支援は習得前のためLevel 3とし、ふりがな・やさしい日本語・BahasaをONにする。Phase 1スクリーンショットのOFF状態より、学習モデルの要件を優先した。
3. 学習画面へ回答前の自信、誤答原因、教材参照、独自模式図を追加した。
4. デスクトップ画面では機能密度を活かすため、分野ボタンを3列にする。

## 修正した差分

- 画面遷移後のスムーズスクロールにより、全画面キャプチャ時に固定ヘッダーが途中へ現れる問題を確認。遷移時スクロールを `auto` に変更し、管理画面の先頭表示を安定化した。

## 結論

主要な情報階層、色、文字、カード形状、ナビ、スマホ密度はPhase 1仕様を維持している。機能要件による追加は明示した4点で、未説明の大きな視覚変更はない。
