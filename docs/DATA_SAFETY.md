# データ・コンテンツ安全方針

## 問題公開ゲート

学習者向け一般公開版で出題できるのは `approved` のみとする。

| 状態 | 意味 | 一般公開 |
|---|---|---|
| draft | 作成途中 | 不可 |
| candidate | 自動検査済み候補 | 不可 |
| source_checked | 公式教材との根拠照合済み | 不可 |
| language_checked | 日本語・インドネシア語確認済み | 不可 |
| approved | 人間最終承認済み | 可 |
| suspended | 再確認中 | 不可 |
| retired | 廃止 | 不可 |

Alphaは内部レビュー目的のため、明示的な設定により `source_checked` を表示する。

## 著作権境界

収録しないもの：

- 公式PDFのページ画像
- 公式教材の写真や図の切り抜き
- 公式確認問題の文面
- 公式ロゴ
- 民間競合サイトの問題、解説、画像、コード
- スクレイピングで取得したコンテンツ

収録するもの：

- 公式教材に根拠を持つ事実・数値・手順
- 新しく作成した問題文、選択肢、解説
- 教材名、版、PDFページ、冊子ページ、章
- 独自作成した模式図

## 更新されやすい情報

法律、最低賃金、統計、試験仕様、家畜防疫情報などは、教材の記述だけで永続的に正しいとは限らない。該当問題には `timeSensitive` を設定し、公開前と教材改訂時に再確認する。

## 学習履歴

Alphaでは個人名、在留資格番号、住所、メール等を保存しない。端末内に保存するのは次だけである。

- 問題ID
- 正誤
- 回答時間
- 使用した言語支援
- 誤答原因
- 習得段階と復習予定
- 模試結果
- 問題レビュー印

管理画面は同一端末の履歴のみを表示する。クラウド同期を導入するときは、本人説明、閲覧権限、保存期間、削除手続を別途定義する。
