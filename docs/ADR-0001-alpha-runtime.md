# ADR-0001：Alphaを依存ゼロTypeScript PWAで実装する

- 状態：採用
- 日付：2026-08-12
- 対象：v0.4.0 Alpha内部レビュー版

## 背景

正本計画ではReact＋Vite＋TypeScriptを第一候補としている。しかし、この制作環境では外部npmレジストリからReact、Vite、Playwright等のパッケージを取得できない。ここで実装を止めると、学習エンジン、PWA、80問データ、誤答原因、模試、管理画面の利用者検証が遅れる。

## 決定

Alphaは次の構成で実装する。

```text
TypeScript namespace
  ↓ tsc outFile
単一 app.js
  + styles.css
  + manifest.webmanifest
  + Service Worker
  + IndexedDB
```

外部ランタイム依存は持たない。コードは型、データ、保存、学習エンジン、模試、画面、イベントを分離する。

## 理由

- 現在の環境でビルド・検査・配布まで完了できる
- 初回読込み後のオフライン利用が可能
- 80問の操作検証を先に進められる
- 実行時AI、APIキー、外部CDNを使わない
- Reactへ移行する場合も、`engine.ts`、`mock.ts`、型、データを再利用できる

## 代償

- Reactコンポーネントではない
- UI更新は文字列レンダリング方式
- 大規模化すると画面責務の分割を再検討する必要がある

## React＋Viteへ移行する条件

次のうち2つ以上に該当した段階で移行ADRを作る。

- 学習者ログインと複数端末同期を追加する
- 会社管理者・問題管理者を別アプリとして分離する
- 問題数が250問を超える
- 複数会社対応が必要になる
- 複雑なフォーム、ルーティング、サーバー状態管理を導入する
- GitHub／Codex環境で依存取得とCIが安定する

## 移行時に維持する境界

- 問題データはUIコードから分離
- 学習エンジンは純粋関数中心
- `approved` のみ公開する安全ゲート
- IndexedDBオフライン優先
- 実行時AIを使わない
