# インドネシア語翻訳ガイド

関連文書: [README](../README.md) / [教材設計概要](PEDAGOGY_SPEC.md) / [学習支援レベル仕様](LEARNING_SUPPORT_SPEC.md) / [レビュー・チェックリスト](CONTENT_REVIEW_CHECKLIST.md)

## 1. 翻訳の役割

インドネシア語は、日本語問題の代替ではなく、日本語を理解するための補助である。問題画面では日本語を先に示し、支援レベルに応じて全文訳・選択肢訳・設問意図・解説を表示する。

## 2. 必須原則

- 原文の意味、条件、主語、対象、時系列を変えない。
- 数字、単位、範囲、比較、否定、例外、頻度、義務・禁止を変えない。
- 原文にない畜産知識、注意、推測、法令解釈を足さない。
- 正解だけを自然・具体的にし、不正解を不自然・曖昧にする翻訳を避ける。
- 正解選択肢の語を問題全文訳へ追加するなど、翻訳によるanswer leakを起こさない。
- 一括機械翻訳を完成品として扱わない。機械翻訳は常にdraftである。
- 公式教材の文章を大量に転載・逐語翻訳しない。アプリ独自の問題文・要約解説を翻訳する。

## 3. フィールド別ルール

### 問題全文訳 `question.id`

- 問題の意味を正確に伝える。
- 「正しい」「誤っている」「最も適切」「含まれない」「原則として」等を省略しない。
- 日本語と同じ問題形式・選択数を維持する。

### 設問意図

`learningSupport.questionPattern` と `lessonObjective.id` を利用し、「何を選ぶか」を短く説明する。答えや正答の特徴を含めない。

例:

- `most_appropriate`: `Pilih satu jawaban yang paling tepat.`
- `incorrect`: `Pilih pernyataan yang salah.`
- `correct`: `Pilih pernyataan yang benar.`
- `select_all`: `Pilih semua jawaban yang benar.`
- `procedure`: `Pilih tindakan atau urutan yang sesuai.`

### 選択肢訳 `choices[].text.id`

- 日本語選択肢と同じ粒度・情報量にする。
- 数字、単位、否定、限定語を保持する。
- 選択肢間で同じ専門語には同じ訳を使う。

### 解説・選択肢別理由

- 正答理由と各不正解理由を訳す。
- 教材に個別理由がないときは、「出典教材の記述と一致しない」と限定し、推測の因果関係を足さない。
- 回答前に表示する翻訳より詳しい内容は、回答後だけに表示する。

## 4. 専門語と共通用語集

- `learningSupport.keyTermIds` から `public/glossary-ja-id.json` を参照し、同じ専門語の訳を統一する。
- 問題全文訳・選択肢訳に現れる専門語は、少なくとも同じ画面での初出時に `インドネシア語（日本語／ふりがな）` の形で示す。同じ画面内の反復は、対応が明らかな場合だけ共通用語集のインドネシア語へ短縮できる。漢字を含まない純カタカナ語は [ふりがな方針](FURIGANA_POLICY.md) に従い、同じ表記を読みとして反復せず `インドネシア語（日本語）` とする。
- 固有名詞・品種名・制度用語は日本語を併記し、意味と試験で読む日本語の対応を失わせない。
- 用語集と異なる訳が必要な場合は、勝手に変更せずレビュー注記へ理由を残す。

## 5. 否定・例外・数量の確認

次を日本語とインドネシア語の両方で明確にする。

| 日本語 | 翻訳で保持する意味 |
|---|---|
| 誤っている / 適切でない | salah / tidak tepat |
| してはいけない | dilarang / tidak boleh |
| 必ず | harus / selalu（文脈で選ぶ） |
| 除く / 含まれない | kecuali / tidak termasuk |
| 原則として | pada prinsipnya |
| すべて選ぶ | pilih semua |
| 最も | paling |
| 以上 / 以下 / 未満 | 以上・以下は境界を含み、未満は含まないことを保持 |

機械的な語対語置換ではなく、文全体で論理が同じかを確認する。

## 6. 例文

重要語に例文を付ける場合は任意とし、次を守る。

- 日本語例文とインドネシア語例文は同じ内容にする。
- 公式教材の新しい事実を導入しない。
- 当該問題の正解を回答前に推測できる例文を使わない。
- 短く、学習対象語の用法が分かる文にする。

## 7. 分離したレビューゲート

1. 機械翻訳または初稿作成: draft。`review.languageId` は `pending_native_review` または `pending`。
2. 日本語確認者: 原文の意味・条件・専門事実との一致を確認する。
3. インドネシア語ネイティブ確認者: 自然さ、曖昧さ、専門語の一貫性を確認する。
4. answer leak確認者: 問題・選択肢・設問意図を横並びで確認する。
5. すべて通過後に限り `review.languageId=pass`。機械翻訳だけで `language_checked` または `approved` にしない。

日本語確認者とインドネシア語ネイティブ確認者は、役割を分けて記録する。同一人物が両方を担う場合でも、各観点の結果を別々に残す。

## 8. 支援レベルと模擬試験

- Level 3: 問題全文訳・選択肢訳を回答前に表示する。
- Level 2: 全文訳は明示操作で開く。選択肢訳は初期非表示とする。
- Level 1: 回答前はインドネシア語を表示せず、回答後に利用可能にする。
- Level 0: 回答前はインドネシア語を表示しない。
- 模擬試験: 回答中・問題一覧・ナビゲーションを含め、教材コンテンツのインドネシア語を一切表示しない。CSS非表示ではなくDOMを生成しない。
